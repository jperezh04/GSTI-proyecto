# OF-04 — Activar CI mínima desde el primer código

**Prioridad:** P0 · **Tamaño:** 3 puntos · **Hito:** M0 · **Responsable sugerido:** Backend/DevOps

**Depende de:** OF-02

**Objetivo:** Detectar errores sin depender del equipo de un integrante.

**Criterios de aceptación:**

- [ ] En cada PR ejecutar formato, lint, comprobación de tipos donde aporte valor, pruebas del código existente y build cuando exista frontend.
- [ ] Fijar dependencias con archivos de bloqueo y acciones externas con SHA verificado; usar permisos mínimos y conservar resultados de las pruebas.
- [ ] Comprobar que un fallo intencional en una rama de prueba hace fallar el check; las pruebas usan muestras pequeñas versionadas y no dependen de portales públicos activos.

**Evidencia / comprobación:** Ejecuciones de CI correcta y fallida; luego retirar el fallo intencional.
