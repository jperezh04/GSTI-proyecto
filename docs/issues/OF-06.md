# OF-06 — Inspeccionar archivos reales y diccionarios

**Prioridad:** P0 · **Tamaño:** 5 puntos · **Hito:** M0 · **Responsable sugerido:** Datos

**Depende de:** OF-05

**Objetivo:** Comprobar qué contienen las fuentes, especialmente el texto.

**Criterios de aceptación:**

- [ ] Descargar recursos públicos disponibles y diccionarios; conservar un manifiesto con fecha, origen, tamaño y hash del archivo.
- [ ] Perfilar tipos, nulos, períodos, identificadores, duplicados y ubicación; verificar si los asientos contienen narración, enlaces a documentos o únicamente metadatos.
- [ ] Documentar muestras de registros reales y campos útiles por fuente; si el recurso completo no es accesible, delimitar la evidencia sin extrapolar cobertura.

**Evidencia / comprobación:** Perfil de datos reproducible y muestras permitidas; no reemplazar el diagnóstico con datos simulados.
