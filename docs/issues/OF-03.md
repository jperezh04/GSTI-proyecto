# OF-03 — Definir requisitos de calidad y Definition of Done

**Prioridad:** P0 · **Tamaño:** 3 puntos · **Hito:** M0 · **Responsable sugerido:** Producto + QA

**Depende de:** OF-01, OF-02

**Objetivo:** Convertir la calidad en condiciones verificables.

**Criterios de aceptación:**

- [ ] Registrar RNF con identificador, escenario, métrica, umbral propuesto, entorno de medición, responsable y evidencia esperada.
- [ ] Cubrir trazabilidad de datos, corrección temporal, seguridad, accesibilidad, rendimiento y recuperación; relacionar cada requisito con una prueba o revisión.
- [ ] Acordar criterios de Ready y Done, severidad de defectos y riesgos que bloquean una entrega; distinguir metas propias de requisitos normativos.

**Evidencia / comprobación:** Matriz RNF–riesgo–prueba y DoD aprobadas por el equipo.
