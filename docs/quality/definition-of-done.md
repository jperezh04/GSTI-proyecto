# OF-03 — Ready / Done (propuesta)

Ready: objetivo y aceptación claros, dependencias resueltas, responsable asignado y datos de prueba identificados. No marcar Ready por tener un borrador.

Done: cada criterio tiene evidencia, otra persona revisó, pruebas pertinentes pasan y documentación está actualizada. Un hallazgo de inviabilidad puede cerrar una investigación; “se investigó” no basta. Merge no implica cierre.

Bloquean entrega: secretos, datos personales innecesarios publicados, resultados inventados, pérdida de trazabilidad, uso de información posterior al corte o duplicación de importes. Severidad crítica: exposición/pérdida de datos o conclusiones inválidas; alta: recorrido principal incorrecto; media: degradación con alternativa; baja: defecto menor.
